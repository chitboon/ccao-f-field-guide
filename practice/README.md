# Practice Bank

Four sets, roughly 125 items. **None of it comes from the exam.** Every item was written from the published objectives and from Anthropic's public course material.

| Set | Items | What it covers |
|---|---|---|
| **[frameworks.md](frameworks.md)** | 28 | The 4Ds and their twelve sub-components, the four-step loop, engagement modes, the four properties, the fine-tuning fingerprints, the Description spectrum |
| **[sequencing.md](sequencing.md)** | 18 | Five-activity ordering items with **five candidate orderings** each, worked by engagement mode |
| **[mock-exam-60.md](mock-exam-60.md)** | 60 | A full-length blueprint-weighted paper, sealed. Sit it in one 120-minute session |
| **[mock-exam-60-key.md](mock-exam-60-key.md)** | — | Key, rationales, domain map, scoring bands |

Start with **frameworks** and **sequencing**. They target the two item types most under-served by other prep material, and they are the two that most often catch prepared candidates by surprise.

Within the frameworks set, **items 1–8 are the priority**. They test the four Ds at the level one candidate recalls being asked about them — the D itself, not its sub-components. The sub-component items after that are still worth doing, but mostly because they make the top-level calls reliable.

Do the mock **last**, in one sitting, against a clock.

## How to use these

**Answer before you open the reveal.** Every item hides its answer behind a fold for a reason. Reading an explanation you would have got right teaches nothing while feeling productive, which is the worst combination available.

**Log misses by trap family, not by item number.** Each item is tagged. What you want at the end of a set is not "I got 14" but "four of my six misses were premature-approval." The first is a score; the second is a study plan.

**Score counts separately from content on multi-response items.** Track two numbers: fully correct, and *partially* correct. Partial selections score zero on the real exam, but they are a **procedural** failure that responds to a habit fix rather than to more study. Averaged into one score, the cheapest available improvement disappears.

**Re-test misses only, two or three days later.** Not the whole set. Spacing is what moves things into durable memory; re-doing items you already know is comfort rather than study.

### The three-bucket miss log

| Bucket | Meaning | What fixes it |
|---|---|---|
| **Didn't know it** | Genuine knowledge gap | Read the source lesson |
| **Misread the item** | Missed a count, a qualifier, a "FIRST" | Pacing discipline, not study |
| **Chose the soft option** | Took the plausible over the structural | The highest-value fix available |

**The distribution matters more than the total.** A 70% with every miss in bucket one is a better position than a 90% with three in bucket three, because bucket one is a reading list and bucket three is a habit.

## On item quality

Every set here was audited for cues that let a reader score well without knowing anything. This is not a formality — the first drafts failed, twice, and in instructive ways.

The sequencing set was initially **16 of 18 answer A**, with a run of thirteen consecutive A's, purely because the author habitually listed the correct ordering first. The frameworks set had **zero A answers at all**. An earlier version of the mock could be beaten by picking the longest option, which was correct in 94% of items.

Current measured state:

| Check | frameworks | sequencing | Target |
|---|---|---|---|
| Answer positions | 8/7/7/6 | 4/4/4/3/3 (A–E) | balanced |
| Longest same-answer run | 3 | 1 | low |
| Correct answer is longest | 25% | n/a | ~25% (chance) |
| Concentration at any single length rank | 36% | n/a | ~25% |
| Length ratio, correct vs distractors | 1.07 | 1.00 | 1.00 |
| Dash / colon / semicolon tell | none | none | none |

Sequencing options are bare number strings of identical length, so the length checks do not apply to that set. Position balance across five letters is what matters there, and the correct ordering is never the numerically lowest of the five — a real tell, because an author who writes the answer first tends to leave it looking tidiest.

**Why this is worth stating.** A practice set with an exploitable cue is worse than none, because it returns a score that feels like knowledge and isn't. If you fork these items or write your own, run the same checks — the failure is easy to introduce and invisible without measuring.

## Contributing items

See [../CONTRIBUTING.md](../CONTRIBUTING.md). In brief: written from published objectives only, correct answer not systematically longest, every distractor wrong for a nameable reason, and tag the trap family the item teaches.

**No exam content, ever.** Describing the *kind* of judgment an item tested is useful and permitted. Reproducing or reconstructing an item is neither.
